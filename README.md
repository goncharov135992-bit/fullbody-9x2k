# Fullbody - офлайн-дневник тренировок

Веб-приложение (PWA) с программой Antitrainer Fullbody: 12 тренировок, 4 недели по 3. Работает без интернета, отмечает подходы и вес, хранит историю на телефоне.

## Что внутри

- `index.html` - экран приложения
- `styles.css` - оформление
- `app.js` - логика и программа тренировок
- `manifest.webmanifest` - описание приложения для установки на iPhone
- `sw.js` - service worker, кэш для офлайна
- `icon-180.png`, `icon-192.png`, `icon-512.png` - иконки
- `fullbody-standalone.html` - вся программа одним файлом, без установки

## Как установить на iPhone

1. Открыть ссылку на приложение в Safari. Chrome и другие браузеры не подойдут, установка работает только из Safari.
2. Нажать кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выбрать «На экран Домой».
4. Открыть приложение с иконки. После первого запуска оно работает без интернета.

Первый запуск обязательно с интернетом: service worker должен скачать файлы в кэш.

## Как отметить тренировку

1. Выбрать неделю и тренировку.
2. Вписать вес и повторы в подходы, нажать круг справа - подход выполнен.
3. При отметке подхода запускается таймер отдыха на 90 секунд: можно поставить на паузу, добавить 30 секунд или убрать 15. Когда время вышло, приложение подаёт звуковой сигнал.
4. Нажать «Завершить тренировку». Запись попадёт в «Историю».

## План

Вкладка «План» показывает все 4 недели и 12 тренировок. У каждой тренировки видно статус: не начата, сколько подходов уже отмечено или дата завершения. Нажатие на тренировку открывает её.

Черновик текущей тренировки сохраняется автоматически: можно закрыть приложение и вернуться.

## Данные

- Хранятся локально в браузере телефона, в localStorage.
- Между устройствами не синхронизируются.
- Очистка данных Safari или удаление приложения с домашнего экрана удалит отметки.
- В «Истории» есть «Экспорт» и «Импорт»: файл JSON можно сохранить в Файлы или отправить себе.

## Обновление

Если меняются файлы, поднять версию кэша в `sw.js`:

```
const CACHE = 'fullbody-v3';
```

После загрузки новой версии приложение обновится при следующем открытии.

## Локальный запуск для проверки

```
cd app
python -m http.server 8765
```

Открыть `http://127.0.0.1:8765/`.

## Публикация на GitHub Pages

1. Создать публичный репозиторий на GitHub.
2. Загрузить в корень репозитория файлы из папки `app` (не саму папку).
3. Settings → Pages → Source: Deploy from a branch → Branch: main, папка `/ (root)`.
4. Через минуту приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.

Ссылку открывать на iPhone в Safari и добавлять на экран Домой.
